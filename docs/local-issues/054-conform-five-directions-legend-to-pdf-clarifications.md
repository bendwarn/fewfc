# 54 Conform Five Directions Legend to the 5.16 PDF clarifications

## Agent Brief

**Category:** bug

**Summary:** Close the remaining Five Directions Legend gaps found by comparing
the official 5.16 PDF with the Web rules.

**Current behavior:**

The engine already transfers the Environment after Sacred Beast damage,
applies Environment doubling before five-element interaction, and charges Void
Meridian-Severing Technique only when an Environment exists. These behaviors
are not all protected by distinguishing tests. In addition, Profession
resistance is currently applied before Shield absorption, so it can incorrectly
reduce or prevent damage that should be received in full by the Shield.

**Desired behavior:**

Five Directions Legend resolution must preserve the PDF's exact timing and
interaction rules. Sacred Beasts resolve against the previous Environment,
ignore Formation effects but not non-Formation rules, and transfer the
Environment afterward. Environment recovery must not be duplicated when the
same Attack also generates the Previous Player's element. Void
Meridian-Severing Technique changes Team HP only after successful Environment
Clearing.

**Key interfaces:**

- The shared Attack resolution pipeline must distinguish damage received by a
  Shield from damage received by its Player before applying Profession
  resistance.
- `AttackPointBreakdown` must retain the ordered Environment Effect and
  five-element interaction that produced the final amount.
- `EnvironmentTransferred` must remain a post-damage semantic event.
- `EnvironmentCleared` must exist only for successful Environment Clearing and
  must atomically carry every Team HP delta.

**Acceptance criteria:**

- [x] Every Sacred Beast calculates damage using the previously existing Environment and emits `EnvironmentTransferred` only after `AttackResolved`, including same-element transfers.
- [x] Sacred Beasts ignore Counter Effects and other Formation effects, but non-Formation Profession resistance still applies when the Player receives damage.
- [x] A Shield receives unreduced Sacred Beast damage; Unloading and elemental resistance do not modify Shield damage.
- [x] Matching-Environment damage doubles before five-element generation, overcoming, or neutralization, with the ordered result represented in `AttackPointBreakdown`.
- [x] When Environment conversion and five-element generation both convert one Attack to recovery, the target Team recovers exactly once.
- [x] Environment-converted recovery is doubled by overcoming and halved with round-up by neutralization.
- [x] Void Meridian-Severing Technique changes Team HP only when it successfully clears an Environment; no Environment, Seal, or any future prevention of Environment Clearing produces no HP change.
- [x] Direct execution, replay, verification, Public Views, and event presentation agree for every clarified path.
- [x] Focused tests cover two-Player and team-mode HP, Shield and no-Shield targets, repeated Environment transfer, overlapping recovery, and prevented Environment Clearing.

**Out of scope:**

- Changing the official Sacred Beast, Environment, or Void Meridian-Severing Formation patterns.
- Adding new Advanced Rule Module toggles.
- Implementing unfinished Hero School abilities beyond the cross-module resistance boundary.
