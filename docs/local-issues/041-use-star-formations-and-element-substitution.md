# 41 Use Star Formations and Star Element Substitution

## Triage

ready-for-agent

## What to build

啟用星辰圖記規則模組時，透過深度規則執行介面實作全部十種星辰技與星辰變牌。隊伍擁有星辰的玩家可查詢並施展其單張星辰擊術及三張星辰技。匹配基礎規則陣法時，所持星辰亦可隱式替代至多一張符合相生屬性的實體牌。

星辰技可用性、驗證、效果結算、查詢結果、公開事件動態呈現及重播均留在同一規則集介面後方。

本議題在比對官方 5.16 PDF 與星辰網頁後重新開啟。既有匹配器能證明存在某種星辰替代，但蓋牌未保留宣告哪張覆蓋牌受替代。

## Acceptance criteria

- [x] 每個隊伍擁有的星辰讓該隊所有玩家可使用官方單張及三張星辰技。
- [x] 僅基礎規則遊戲不匹配或公開星辰技及星辰變牌。
- [x] 五種單張星辰擊術是不同屬性的攻擊陣法，攻擊點數固定為 10。
- [x] 五種三張星辰技使用官方屬性組合，攻擊點數為等級總和乘三。
- [x] 已接受的三張星辰技使回合抽牌增加一次，並破除提供該技的星辰。
- [x] 傷害被防止不會取消三張星辰技的回合抽牌加成或星辰破除。
- [x] 星辰擊術及三張星辰技參與正常五行生剋、防護罩及反制效果結算。
- [x] 星辰技不是基礎規則陣法，不能由幻化複製。
- [x] 星辰變牌匹配基礎規則陣法時，隱式考量至多一張符合條件的實體牌。
- [x] 星辰變牌不能匹配星辰技，且不修改實體牌或牌定義。
- [x] 可施展陣法查詢及陣法提交使用相同匹配規則。
- [x] Web 陣法流程呈現及提交星辰技，無須星辰專屬客戶端命令。
- [x] 每條星辰技及替代路徑的正規事件、公開事件動態、直接執行及重播保持等價。
- [x] 使用星辰替代的陣法匹配選項指出受影響實體牌與其解讀後屬性，不修改牌資料。
- [x] 透過星辰變牌覆蓋被動術式時，正規事件及遊戲狀態記錄宣告的受影響牌。
- [x] 擁有者可重新連線並恢復覆蓋時的替代宣告；其他玩家及觀戰者不會得知額外隱藏牌資訊。
- [x] 直接執行、重播、驗證、可執行行動及 Web 提交對確切替代牌的認定一致。
