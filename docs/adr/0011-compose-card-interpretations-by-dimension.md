# Compose Card Interpretations by dimension

Card Interpretation Layers apply in effect order: a later layer replaces an
earlier value only for the dimensions it specifies, while unrelated dimensions
continue to compose. Sacred Art Multiplicity applies after element and level
interpretation, gives both match slots the same effective values, and is
incompatible with Star Element Substitution both before and after expansion.
The previous single-source model was rejected because Fire Spirit level changes
must compose with unrelated interpretations without mutating Card data, while
Sacred Art's explicit physical-Card restrictions must remain enforceable.
