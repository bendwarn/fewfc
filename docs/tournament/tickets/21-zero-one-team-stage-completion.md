# 21：零隊／一隊後續階段與整場閉合

**Priority:** P2

**What to build:** 已公告的後續階段在來源完成且資格確定後，只有一隊便直接成為階段勝者，零隊明示原因並取消；網站與整場完成權威一致。未決來源不能當零隊，也不建立假比賽或默默略過階段。

**Blocked by:** [15：至少兩隊的多階段自動晉級](15-automatic-stage-transition.md)、[16：整場完成權威與賽後公開](16-completion-and-publication.md)、[19：修復瑞士雙負隊伍再被配入後輪](19-swiss-double-loss-exit.md)、[20：循環與淘汰雙負、空缺自動收尾](20-double-loss-vacancy-completion.md)

**Status:** ready-for-agent

**類型：** 新增／接線

## 驗收條件

- [x] 來源真正完成且資格確定後，後續公告階段只有一隊便直接成為該階段勝者，不建立假交手／Game。
- [x] 零隊明示無合格參賽者、取消及原因，保留無勝者事實，不默默略過公告階段。
- [x] 至少兩隊仍走 15；未完成來源、未決資格或名次不能冒充零／一隊。資格來源指向明確空缺名次時該位置沒有隊伍，不遞補，資格全數確定後按實際隊數處理。
- [x] 網站、階段權威及整場完成一致；案例包含零隊、一隊、未決來源與一般重試不重複建立／取消。
