# 13：瑞士多輪自動配對與排名

**Priority:** P1

**What to build:** 依已公告的瑞士輪數與完整瑞士政策自動配對後輪、回收結果並更新戰績；四項積分預設 3／1／0／3、允許賽前自訂非負整數，和局折算、對手勝率上下限、輪空取值與同分鍵也須在公告中完整明示並依公告執行，不可另用未公告公式。晉級與前三名沿用 14；中途只顯示目前自身勝場，不顯示暫時名次或對手勝分／負分。符合瑞士規則的候選配對仍有多個時，以固定保存的抽籤種子決定，重試不重抽、不要求主辦逐輪介入，也不產生正式名次；網站能走完正常多輪，不只證第一輪。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 接線／修正／補驗證

**待修正：** 現有設定接受非零敗場積分，但主積分累計未套用；須依公告修正四項合法積分的累計，不能靜默忽略或拒絕已允許的非零敗分，也不能把有欄位當作已正確計分。

## 驗收條件

- [ ] 依公告輪數走完多輪；中途只顯示目前自身 Match 勝場，不顯示暫時名次或對手勝負分。
- [ ] 勝／和／負／輪空預設 3／1／0／3，四項自訂非負整數均依公告累計，包括非零敗分；輪空積分不增加實際勝場。
- [ ] 合法候選配對仍有多個時使用固定保存的抽籤種子，重試不重抽或建立第二份配對，不需主辦逐輪處置。
- [ ] 階段末晉級／前三名沿用 14；公告內的瑞士政策不作隱藏預設，配對抽籤不能決定正式名次。
- [ ] 多輪案例核對積分、配對版本、輪空及網站勝場；19 負責雙負退出迴歸，不用舊單輪綠燈代替修復。
