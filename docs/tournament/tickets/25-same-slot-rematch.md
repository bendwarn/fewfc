# 25：重賽與已開打後續交手的處置

**Priority:** P3

**What to build:** 裁判能先暫停受影響且已開打的賽程，直接建立新局取代原交手同一局位置；原局不再計入有效局數及比分，原始紀錄、理由與更正關係仍可查核。沿用原局先後手，重置階段完整時計，不把重賽默當淘汰和局加賽。舊房是否留存由實作選擇，但舊局不能再回報有效結果。

**Blocked by:** [23：裁判暫停、恢復與判棄權介面](23-referee-clock-and-forfeit.md)、[24：賽中改判與未開局房間撤銷重建](24-correction-and-waiting-room-rebuild.md)

**Status:** ready-for-agent

**類型：** 新增／政策已確認

**政策狀態：** 同位置取代、先後手、時計、新舊結果關係及舊房留存裁量均已確認，詳見[設計的重賽政策](../competitive-play-design.md#競賽重賽)；功能仍在 P3，尚未實作或驗證。

## 驗收條件

- [ ] 重賽沿用被取代局先後手，不重抽或改由原局敗方選擇；重置該階段完整主時間／讀秒，清除舊局讀秒進入事實，不限時設定仍不限時。
- [ ] 裁判先暫停受影響且已開打的賽程，網站顯示待處置，不假裝撤銷或回滾已發生遊戲。
- [ ] 新局占原 Match 的同一局位置，只有有效替代局結果計入比分／賽程；原始 Game Record、競賽判定、理由與取代關係保留，舊房可關閉或存檔而不需維持可操作。
- [ ] 原局的遲來操作／結果不能污染有效比分；一般重試不建立多個有效替代局，不覆寫原始 canonical 歷史。
- [ ] 元件驗證正常重賽、先後手／時計、授權／過期拒絕與一般重試；重賽不誤當淘汰 Draw 加賽，不把未執行的案例宣稱為通過。
