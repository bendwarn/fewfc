# 28：跨房故障、撤銷競態與平台重啟矩陣

**Priority:** P3

**What to build:** 對已完成的開房、結果、裁判及更正流程注入交付遺失、撤銷與真開局競態、重啟等故障，確認可恢復、不重複計分且新舊房間隔離。與既有正常非同步流程必要保護分開，不以這張延後票省略基本防重複或順序驗證。

**Blocked by:** [22：正式辦賽範圍的集中總驗收](22-first-event-integration-validation.md)、[26：跨階段改判的資格與賽程影響](26-cross-stage-correction.md)、[27：賽後更正留痕且不重開賽程](27-post-event-correction.md)

**Status:** ready-for-agent

**類型：** 進階恢復驗證

## 驗收條件

- [ ] 對已完成契約注入交付遺失、延遲、重複及亂序，確認可恢復且不重複建房／計分。
- [ ] 注入撤銷與 GameStarted 競態，只採權威成立路徑，舊房／命令與新房隔離。
- [ ] 以真平台或等效可證實的持久狀態重啟驗證交手／局號、固定成員、時計及結果恢復；普通程序重跑不當 Durable Object 重啟實證。
- [ ] 逐項記錄注入點、權威觀測、重啟方式及可恢復範圍；無證據維持 HOLD，不以本票豁免前票的基本 FIFO／防重複。
- [ ] 矩陣可重現且兩軸審核通過才放行其範圍，不外推未覆蓋系統。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
