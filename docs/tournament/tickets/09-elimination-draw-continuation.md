# 09：淘汰和局判定與時計沿用加賽

**Priority:** P1

**What to build:** 淘汰和局依讀秒進入事實決定競賽勝負，或自動接續沿用剩餘時計的加賽；原始 Draw 保留。已判出敗方但仍需普通下一局的分支沿用隊長選擇，不誤當時計沿用加賽。

**Blocked by:** [08：普通下一局與敗方隊長先後手選擇](08-next-game-first-player.md)

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [ ] 淘汰正常勝負採正常結果，不受較早進入讀秒影響；Draw 且可區分讀秒先後才判先進入者負。
- [ ] 兩隊皆未或同時進入讀秒時自動接續加賽，不補回主時間；不限時仍不限時，再次 Draw 重複政策且無加賽上限。
- [ ] 保留原始 Draw，另記 Competition Ruling、原因及時計事實，不覆寫結論或在 GameEnded 後追加賽務 canonical 事件。
- [ ] 已判出敗方但仍需普通下一局時走 08；真正同時耗盡讀秒走雙負，不以加賽替代。
- [ ] 分別驗證上述分支；循環／瑞士普通 Draw 不套用淘汰判負，也不把排名同分當遊戲 Draw。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
