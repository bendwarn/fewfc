# 24：賽中改判與未開局房間撤銷重建

**Priority:** P3

**What to build:** 有權限的裁判改判後，受影響且尚未開打的下輪房間可撤銷重建，再公告新的開始時間；舊房與舊命令失效，保留原始及更正紀錄。包含既有循環改判修補的延後邊界，不假裝已開局也能撤銷成功。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 接線／擴充／補驗證

## 驗收條件

- [ ] 有權限且無自身交手利益衝突的裁判可附理由更正，保留原始結論、更正及操作者關係。
- [ ] 受影響下輪尚未真正開局時，持久撤銷舊房並重建；舊入口／命令不能繼續使用。
- [ ] 主辦重新公告 T，全部新房再次至少提前五分鐘就緒，不暗中順延或沿用舊 T。
- [ ] 與 GameStarted 競態或已開打不能宣稱撤銷成功；說明受影響狀態，依 25 分流。
- [ ] 元件涵蓋 Waiting 成功路徑、真開局負控制及一般重試維持同一更正／開房版本。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
