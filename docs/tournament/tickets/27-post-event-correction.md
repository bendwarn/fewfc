# 27：賽後更正留痕且不重開賽程

**Priority:** P3

**What to build:** 整場結束後可有原因地更正允許的結果／名次，保留原始與更正歷史；需要新增比賽或重賽才成立的更正明確拒絕，不重新開賽，也不覆寫原始遊戲結論。

**Blocked by:** [16：整場完成權威與賽後公開](16-completion-and-publication.md)、[24：賽中改判與未開局房間撤銷重建](24-correction-and-waiting-room-rebuild.md)

**Status:** ready-for-agent

**類型：** 新增／擴充

## 驗收條件

- [ ] 整場結束後，有權限且無自身交手利益衝突的裁判可附理由更正允許結果／名次，原始與更正歷史可查。
- [ ] 需要新比賽或重賽才成立的更正明確拒絕，不重開賽程或轉回進行中。
- [ ] 原始 Game Conclusion 不被覆寫，公開更正可追溯且凍結牌組／合法公開政策不變。
- [ ] 元件驗證允許留痕、需新比賽而拒絕，以及未授權／過期／重複更正不能寫出第二份結果。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
