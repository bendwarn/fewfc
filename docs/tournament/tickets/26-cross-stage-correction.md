# 26：跨階段改判的資格與賽程影響

**Priority:** P3

**What to build:** 來源賽果更正影響已建立的後續階段時，網站能查明資格及配對影響，依尚未開打／已開打分流撤銷重建或裁判處置，不靜默回滾已發生的比賽。

**Blocked by:** [15：至少兩隊的多階段自動晉級](15-automatic-stage-transition.md)、[25：重賽與已開打後續交手的處置](25-same-slot-rematch.md)

**Status:** ready-for-agent

**類型：** 新增／擴充

## 驗收條件

- [ ] 來源更正影響後續已建立階段時，網站可查原資格、種子、配對及受影響交手。
- [ ] 未開打依 24 撤銷重建，已開打依 25 確認政策暫停／處置，不靜默回滾。
- [ ] 保留未受影響階段與真實結果，保存跨階段更正因果，不擴大改判或重新抽籤。
- [ ] 相依完成後，用 Waiting／已開打窄案例驗證過期預覽、錯誤階段及一般重試，不能自行重定義 25。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
