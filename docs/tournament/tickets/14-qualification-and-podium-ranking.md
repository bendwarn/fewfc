# 14：晉級與前三名的排序判定

**Priority:** P1

**What to build:** 涉及晉級資格與前三名的排序，先比自身積分高，同分才比勝分多、負分少；勝分／負分取自本階段不同對手的最終交手戰績，權威排名、資格解析及網站呈現一致。不比較血量或耗時，也不新增為排名收集終局血量／主時間的帳本或樣本。全項相同由主辦限定判斷、公開理由且迴避利益衝突，未決前阻擋受影響的資格／完賽。此入口屬本票，不要求先完成一般裁判介面；不改動 09，也不新增排名同分加賽或第四名以後的獎牌排名賽。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 新增／政策已確認

**政策狀態：** 完整定義只見[設計的排序定義](../competitive-play-design.md#晉級與前三名的排序判定)。血量／耗時、其有效樣本／無樣本與平均值已移出需求；政策確認不代表已有實作或驗證。

## 驗收條件

- [ ] 權威排名、資格解析及網站結果先比自身積分高，同分才比勝分多、負分少。
- [ ] 不同對手每隊只計一次，取其本階段最終 Match 勝敗且包括與自己交手；不跨階段或以 Game 勝敗／勝率代替。
- [ ] 未開打缺席配對排除於對手集合；合法戰績、和局、雙負、輪空及取消依政策處理，不造勝敗。
- [ ] 血量、耗時、種子或配對抽籤不影響正式排名；不新增排名用帳本、平均值或同分加賽。
- [ ] 全同群組只允許主辦／無利益衝突的指定裁判判斷，理由必填且公開；不能改非同分隊伍，過期狀態或無權限決定被拒絕。
- [ ] 判斷未決時阻擋受影響的晉級、前三名及整場完成；案例覆蓋每項比較、全同等待與限定入口，不依賴一般裁判介面。
