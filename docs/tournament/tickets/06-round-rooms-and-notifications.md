# 06：固定輪次自動開房、發布時間與玩家入口

**Priority:** P1

**What to build:** 已確定的輪次自動建立固定房間，沿用首輪時間或依整輪實際就緒時刻產生後續時間。房間可進入後通知固定成員，賽事頁直接提供玩家目前入口；通知未送達也不需要主辦另傳交手識別碼。

**Blocked by:** [01：準備即報到，全員準備立即開局](01-ready-check-in-start.md)、[05：自動抽籤並建立首輪賽程](05-initial-seeding.md)

**Status:** ready-for-agent

**類型：** 新增／接線

## 驗收條件

- [ ] 確定輪次自動建立綁定交手、局號及凍結成員的固定房間，網站提供正確玩家入口。
- [ ] 首輪沿用公告 T 並至少提前五分鐘就緒；延誤不得暗改 T 或假裝滿足窗口。
- [ ] 後續輪次／新階段以全部房間可進入的權威 R 保存並發布向上取整到分鐘的 R＋五分鐘；部分房間未就緒不能冒充整輪就緒。
- [ ] 可進房後才觸發既有成員通知；未收到在線推播仍可從賽事頁進房，不要求主辦傳識別碼。
- [ ] 案例核對分鐘精度、完整窗口、固定成員、通知觸發點與一般重試；通知不是開房或報到成功的證據。
