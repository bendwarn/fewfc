# 06：固定輪次自動開房、發布時間與玩家入口

**Priority:** P1

**What to build:** 已確定的輪次自動建立固定房間；首輪沿用公告時間，後續輪次與階段依前輪完成後的兩段五分鐘窗口排程。房間可進入後通知固定成員，賽事頁直接提供玩家目前入口；通知未送達也不需要主辦另傳交手識別碼。

**Blocked by:** [01：準備即報到，全員準備立即開局](01-ready-check-in-start.md)、[05：自動抽籤並建立首輪賽程](05-initial-seeding.md)

**Status:** ready-for-agent

**類型：** 新增／接線

## 驗收條件

- [x] 確定輪次自動建立綁定交手、局號及凍結成員的固定房間，網站提供正確玩家入口。
- [x] 首輪沿用公告 T 並至少提前五分鐘就緒；延誤不得暗改 T 或假裝滿足窗口。
- [x] 前輪全部結果與晉級配對權威確定後，自動固定完整下一輪並開始建房；A＝向下取整到分鐘的前輪完成時間 E＋五分鐘。只有整批房間都可進入時才在 A 開放並公告，T＝A＋五分鐘，使 E 到 T 不超過十分鐘且公告後保有完整五分鐘窗口。
- [x] 建房或放行未能在 A 前完成時 fail closed；不開放部分房間、不縮短五分鐘窗口、不暗中順延 T，並留下可明示處置的持久狀態。
- [x] 可進房後才觸發既有成員通知；未收到在線推播仍可從賽事頁進房，不要求主辦傳識別碼。
- [x] 案例核對兩段窗口、分鐘精度、完整窗口、固定成員、通知觸發點與一般重試；通知不是開房或報到成功的證據。
