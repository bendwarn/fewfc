# 02：開局前斷線取消準備與報到

**Priority:** P0

**What to build:** 等待房玩家失去有效連線後，網站與權威狀態都撤回準備／報到；重連須重新按準備，不能沿用舊狀態開局。已開局的斷線仍沿用既有時計，不退回等待房。

**Blocked by:** 無（無功能票前置；仍須依索引協調唯一寫入權）。

**Status:** ready-for-agent

**類型：** 修正

## 驗收條件

- [x] 尚未真正開局時，取消準備或失去有效連線會撤回該玩家的準備與報到，權威狀態及網站同步。
- [x] 團體任何固定成員未連線或未準備時不能開局；重連不恢復舊準備，須重新按準備。
- [x] 斷線與開局競態只採權威成立的一次轉換；已開局不退回等待房，仍沿用既有時計。
- [x] 案例涵蓋等待房斷線、重連及已開局的負控制，不以推播是否送達作為正確性依據。
