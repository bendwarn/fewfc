# 20：循環與淘汰雙負、空缺自動收尾

**Priority:** P2

**What to build:** 共用「雙負隊伍退出本階段，不再參加後續交手」規則，依賽制處理原賽程的取消與空缺。重用已修的循環退出與單敗空缺能力，完成當前版本審核及收尾接線；保留已確定名次，無合格人選的位置明示空缺，不造勝者、對局或遞補名次，允許合法收尾。

**Blocked by:** [11：單敗自動季軍賽與階段收尾](11-single-elimination-bronze.md)、[12：雙敗勝敗部與總決賽重置賽](12-double-elimination-finals.md)、[17：報到截止自動處理缺席](17-automatic-no-show-rulings.md)、[18：真讀秒耗盡與同時耗盡雙負](18-byoyomi-expiration-rulings.md)

**Status:** ready-for-agent

**類型：** 修後審核／接線／補驗證

**拆分決定：** 維持一票，不拆成循環、單敗、雙敗三票；三個驗收分支共同證明同一退出規則，各賽制差異不是必須分票的理由。

**政策狀態：** 名次空缺的取值只見[設計](../competitive-play-design.md#雙負空缺與後續階段)，仍須完整現況審核及元件實證，不以政策確認放行。

## 驗收條件

- [ ] 同一共同規則將 DoubleLoss 兩隊退出本階段，後續賽程及房間入口不再安排其出賽。
- [ ] 循環取消退出隊伍尚未開打的後續交手，保留已完成結果，不給其他隊伍虛構勝利、勝場或積分。
- [ ] 單敗沿原位置傳播空缺，合法對手輪空；雙空位繼續傳播，不把空位當隊伍或再判雙負。
- [ ] 單敗決賽與季軍路徑正確收尾；真正決賽雙負呈現冠軍空缺，不造冠亞軍或復活／遞補。
- [ ] 雙敗退出隊伍不進敗部或重出賽，勝敗部、總決賽及重置賽的空缺均有正確進度，不造交手／勝局。
- [ ] 雙敗敗部決賽雙負後，剩餘勝部冠軍沿原空位／輪空規則成為冠軍，亞、季軍明示空缺，不讓退出隊伍復出或遞補。
- [ ] 總決賽／必要重置賽雙負時，冠、亞軍空缺，已正常決出的第三名保留；空缺是已決定的無人取得，不阻擋合法階段／整場收尾，未決結果仍阻擋。
- [ ] 三賽制在同票驗證一般重試不重複退出，重新審核完整現況與既有窄修，不以歷史 PASS 代替本票完成。
