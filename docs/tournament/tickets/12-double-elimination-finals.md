# 12：雙敗勝敗部與總決賽重置賽

**Priority:** P1

**What to build:** 雙敗的正常勝敗部晉級與必要重置賽使用共用開房流程，自動接續並呈現正確交手、結果與名次。重置賽是新的賽事交手，不新增另一種房間或重寫賽程演算法。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [x] 正常雙敗更新正確勝敗部與敗方落點，固定成員進入正確後續交手，網站可查看路徑。
- [x] 勝部冠軍首次總決賽勝出則結束；敗部冠軍首次勝出則自動建立必要重置賽再決勝。
- [x] 重置賽是新 Match 並走共用開房／結果流程，不誤當 Draw 時計接續；一般重試不重置兩次。
- [x] 必要結果未完成不得收尾；正常前三名由合法賽果決定，空缺分支由 20 按已確認政策處理，不造名次或遞補。
- [x] 賽程與網站投影案例涵蓋有／無重置賽的完整正常分支，不只驗證 bracket 產生。
