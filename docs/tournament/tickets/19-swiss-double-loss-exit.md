# 19：修復瑞士雙負隊伍再被配入後輪

**Priority:** P2

**What to build:** 從已重現的合法雙負結果到後輪配對與網站賽程投影，兩隊都確實退出本階段、不再出賽；後輪只使用仍合法的隊伍。既有積分通過不能代替退出後輪的修復證據。

**Blocked by:** 無（無功能票前置；仍須依索引協調唯一寫入權）。

**Status:** ready-for-agent

**類型：** 修正／補驗證

**實作與驗證：** 已修正並限定 PASS；Rust 專項 2 pass／0 fail，涵蓋六隊雙負退出與奇數合格隊伍正常輪空。提交前以目前工作樹重新建置，完整 Cargo 735 pass／0 fail，網站賽程投影 10 pass／0 fail。修正與回歸案例納入本票提交。

## 驗收條件

- [x] 沿已重現合法首輪雙負路徑保留迴歸案例，修後兩隊退出本階段，後輪配對及網站不再出賽。
- [x] 後輪只用仍合法隊伍；雙負各記一敗，不造勝場、和局或退出隊伍的後續交手。
- [x] 保留正常奇數隊輪空及已完成真實結果，不刪整輪或偽造對手來躲開問題。
- [x] 至少驗證原六隊／兩輪迴歸、後輪投影及結果重試不重複記敗／恢復資格；舊單輪積分綠燈不能替代修復證據。
