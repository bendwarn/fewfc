# 10：結果驅動循環與單敗自動下一輪

**Priority:** P1

**What to build:** 真實交手結果只接收一次；整輪收齊後自動更新賽程、配對並開下一輪，不再由主辦逐輪公告。先以循環與單敗正常路徑驗證共用推進，未完成前輪或未決賽果不能觸發下一輪。

**Blocked by:** [06：固定輪次自動開房、發布時間與玩家入口](06-round-rooms-and-notifications.md)、[07：權威隊伍時計接通真正對局](07-authoritative-game-clock.md)

**Status:** ready-for-agent

**類型：** 新增／接線

## 驗收條件

- [x] 接收真正完成的 Match 結果，不把一個 Game 結束當整場交手完成；相同結果只計入一次。
- [x] 循環與單敗正常賽程更新權威狀態及網站；整輪必要結果收齊且配對確定才自動物化下一輪。
- [x] 重用共用開房、時間與通知，不需主辦逐輪公告，也不新增每賽制房型。
- [x] 未完成前輪、未決賽果或錯誤交手身分不能推進；兩賽制各以至少兩輪窄案例驗證一般重試不重建或重複計分。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
