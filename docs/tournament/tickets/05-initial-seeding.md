# 05：自動抽籤並建立首輪賽程

**Priority:** P1

**What to build:** 依公告方案與凍結名單，自動決定並保存首輪種子，產生可查看的首輪配對與正常輪空；重試不重抽、不重建，不要求截止後由主辦確認。

**Blocked by:** [03：賽前公告完整競賽方案](03-competition-announcement.md)、[04：報名截止自動鎖定名單與牌組](04-registration-freeze.md)

**Status:** ready-for-agent

**類型：** 新增／接線

## 驗收條件

- [ ] 依公告方案與合格凍結名單自動建立首輪，玩家可查自己的配對或合法輪空。
- [ ] 沒有種子來源時自動抽籤並持久保存；有賽前指定來源時沿用公告，不在 F 後要求主辦確認。
- [ ] 相同請求及一般重試沿用同一種子／賽程，不重抽、不建第二份首輪。
- [ ] 至少兩隊及奇數隊案例驗證輪空不造 Game 勝局或實際交手勝場，固定身分與種子可供開房使用。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
