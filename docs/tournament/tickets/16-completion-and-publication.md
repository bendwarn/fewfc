# 16：整場完成權威與賽後公開

**Priority:** P1

**What to build:** 所有公告階段實際收尾、結果收齊且無未決案件後自動結束整場並顯示結果，才開放允許的重播與凍結牌組。先以單階段唯一排名的賽事驗證，未建立的已公告階段及未決前三名都須阻擋誤結束。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 新增

## 驗收條件

- [ ] 全部公告階段已完成或明確取消、結果收齊且無未決案件／名次後，自動結束整場，不需主辦確認。
- [ ] 單局或單階段完成、仍有未建立的公告階段或未決前三名時不能誤結束；已明確空缺的名次不是未決，不因獎牌不足阻擋完賽。
- [ ] 整場進行中禁止競賽觀戰與提前公開重播；裁判查核及自由對局政策不被誤改。
- [ ] 真正結束後才公開允許資訊重播與鎖定牌組組成，不洩露洗牌順序、完整隱藏狀態或後改帳號牌組。
- [ ] 先以單階段唯一名次元件驗證完成／公開授權與重試，不要求先完成所有多階段或賽後更正。
