# 23：裁判暫停、恢復與判棄權介面

**Priority:** P3

**What to build:** 指定裁判可透過網站使用已具備的時計控制並判棄權、記錄原因，不能裁決自身交手；結果與賽程一致。只補尚缺的入口、授權及流程，不重做已放行的暫停／恢復核心。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 新增入口／權限整合

## 驗收條件

- [ ] 指定裁判在網站可暫停／恢復合法交手時計，權威剩餘一致且不重置已耗時間。
- [ ] 可附理由判棄權並回收合法競賽結果更新賽程，不覆寫原始 Game Conclusion。
- [ ] 無權限或裁決自身交手者被拒絕；理由、操作者及結果可查核，過期／重複請求不造成第二次判定。
- [ ] 元件補入口、授權、暫停中操作限制及結果更新，重用已放行核心，不重做時計。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
