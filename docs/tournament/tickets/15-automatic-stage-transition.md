# 15：至少兩隊的多階段自動晉級

**Priority:** P1

**What to build:** 來源階段真正完成且資格唯一確定後，自動保存下一階段、沿用來源與種子映射、切換時計並開房；參賽者看得到新階段入口。未決資格維持等待，不能冒充零隊或先猜晉級者。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [ ] 來源階段真正完成、至少兩隊的資格唯一確定後，自動保存下一階段及原資格／種子映射。
- [ ] 新階段使用自身公告時計與交手設定，固定成員開房並取得時間、通知及入口。
- [ ] 來源未完成或資格／限定主辦判斷未決時保持等待，不猜隊伍或冒充零／一隊。
- [ ] 一般重試不重建階段或重抽種子；元件案例包含權威保存與網站入口，不只跑既有純解析／假 bridge；零／一隊由 21。
