# 04：報名截止自動鎖定名單與牌組

**Priority:** P1

**What to build:** 到截止時自動凍結合格隊伍與參賽牌組，明示排除原因，不需主辦按鎖定。跨截止的遲來提交不能改動凍結版本；後續房間沿用此版本，而非帳號後改牌組。

**Blocked by:** 無（無功能票前置；仍須依索引協調唯一寫入權）。

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [x] F 自動凍結名單、成員確認、必要牌組及隊長資料完成確認，不需主辦按鎖定；不完整隊伍明示排除原因。
- [x] 跨 F 的遲來提交不能改凍結版本，以權威接受點而非瀏覽器時間判斷是否逾期。
- [x] 固定參賽版本可交付後續房間，帳號後改牌組不影響本賽事；資料完成確認不冒充房間報到。
- [x] 補截止接受點與快照交付案例，重用已通過的凍結能力，不新增舊賽事相容或初始生命專項測試。
