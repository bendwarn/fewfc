# 08：普通下一局與敗方隊長先後手選擇

**Priority:** P1

**What to build:** 尚未結束的交手完成一局後，正確敗方隊長可在網站選先後手，系統提供下一局固定房間並重置主時間；沒有競賽勝負的普通和局按政策交換，不重複建立新局。

**Blocked by:** [07：權威隊伍時計接通真正對局](07-authoritative-game-clock.md)

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [x] 交手未完成時，終止一局只建立一次普通下一局；相同結果重試不重複建房。
- [x] 有競賽勝負時只有正確敗方隊長能選先後手，其他人或過期局號被拒絕。
- [x] 無競賽勝負的普通和局按政策交換；已被判出競賽敗方的 Draw 仍走敗方選擇。
- [x] 網站可完成選擇並進新房間，固定成員與主時間重置一致；不誤用加賽時計接續。
