# 07：權威隊伍時計接通真正對局

**Priority:** P1

**What to build:** 正常操作時，房間與時計顯示一致地處理準備選牌、同隊共享、他隊回合外選擇、主時間零不限時與重連接續；只扣需要玩家操作的隊伍。重用已放行的時計核心、JSON 契約與路由。

**Blocked by:** [01：準備即報到，全員準備立即開局](01-ready-check-in-start.md)

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [x] 真正開局後，準備選牌、行動及必要選擇接到權威隊伍時計，網站顯示一致。
- [x] 同隊共享一份主時間；隊友沿本行動回合額度，他隊作答先扣該隊主時間再用獨立讀秒，不因玩家不同重置。
- [x] 有限主時間不足時先扣完剩餘再接完整讀秒；同行動連續操作不重置，讀秒不累積。
- [x] 設定主時間 0 時所有操作視窗不限時；有限額度耗盡的剩餘 0 不誤當不限時。
- [x] 已開局斷線持續扣時、重連接續；等待、系統自動結算及暫停不補造玩家耗時。
- [x] 以元件／純模組核對正常路徑及必要 DTO 契約；超時裁決與進階重啟分別由 18、28 處理。
