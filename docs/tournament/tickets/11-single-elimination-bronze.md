# 11：單敗自動季軍賽與階段收尾

**Priority:** P1

**What to build:** 兩支合格半決賽敗隊自動進入季軍賽，與冠軍賽同輪、沿用該階段設定，決出唯一第三名；冠軍賽先完成不能提前結束階段。

**Blocked by:** [10：結果驅動循環與單敗自動下一輪](10-automatic-round-progression.md)

**Status:** ready-for-agent

**類型：** 新增

## 驗收條件

- [ ] 正常單敗兩支合格半決賽敗隊自動進唯一季軍賽，沿用階段交手門檻與時計。
- [ ] 與冠軍賽同輪，兩路均使用共用固定開房、通知、入口及結果回收。
- [ ] 冠軍賽先完成時不得提前結束階段；兩路收尾才確定前三名。
- [ ] 案例覆蓋不同完成順序與結果重試；不建立第四名以後獎牌賽或復活退出隊伍，空缺分支由 20 驗證。

共用驗收與工作規則見[票據索引](README.md#共用驗收與工作規則)；產品政策見[競賽設計](../competitive-play-design.md)，現況與放行證據見[審核關卡](../competition-review-gates.md)。
