# 18：真讀秒耗盡與同時耗盡雙負

**Priority:** P2

**What to build:** 權威讀秒真正耗盡時自動停止後續玩家操作並回收競賽判定；依實際耗盡先後判負，唯同一時刻耗盡才雙負。延遲一次看到兩隊過期不冒充同時耗盡，原始遊戲結論不被覆寫。

**Blocked by:** [07：權威隊伍時計接通真正對局](07-authoritative-game-clock.md)

**Status:** ready-for-agent

**類型：** 接線／補驗證

## 驗收條件

- [x] 需要隊伍操作的權威讀秒真正耗盡才自動判負；只是進入讀秒不判負。
- [x] 實際不同截止時刻依先後判負；延遲一次看到兩隊過期仍不能冒充同時耗盡。
- [x] 截止時刻真正相同才記 DoubleLoss，不依遍歷或輪詢順序造勝者。
- [x] 裁決後停止過期玩家操作並交付判定／證據；不覆寫原始結論或補造 GameEnded 後事件。
- [x] 元件／純模組涵蓋不同及同時截止、重複觸發與結果回收；不外推真平台重啟。
