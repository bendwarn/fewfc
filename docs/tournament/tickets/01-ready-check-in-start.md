# 01：準備即報到，全員準備立即開局

**Priority:** P0

**What to build:** 一個已授權的固定交手可在公告時間前自動真正開局；開局證據、賽程與時計一致，包含需要遊戲準備選牌的規則。先整理公告時間與真正開局的共同契約，保留身分、防重複與交付順序保護，不只移除單一時間判斷。

**Blocked by:** 無（無功能票前置；仍須依索引協調唯一寫入權）。

**Status:** ready-for-agent

**類型：** 修正／接線／補驗證

## 驗收條件

- [x] 固定交手全員有效連線且按準備後即完成房間報到；開賽授權成立便真正開局，可早於公告 T，不等待同輪其他交手。
- [x] 進房、物化房間、玩家準備及真正開局保持不同事實；直接行動與先進入遊戲準備選牌兩條路徑均交付一致的開局證據。
- [x] 不合格身分、過期房間及未成立的授權不能開局；重複準備與一般交付重試不重開局。
- [x] 元件案例核對房間、賽程與時計的正常交付，不只測移除 T 的下限判斷。
