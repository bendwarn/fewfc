# 競賽對局與線上賽事設計

產品政策唯一來源。2026-10-08 完整共識、2026-10-09 正常完賽訪談及 2026-10-10 排序、名次空缺與重賽政策的已確認更新記於本文；政策確認不等於功能已實作。實作進度與驗證見[目前審核關卡](competition-review-gates.md)，詞義見 [CONTEXT](../../CONTEXT.md)。

## 名稱與範圍

| 用途 | 正式名稱 | 副標 |
| --- | --- | --- |
| 現有玩法 | 自由對局 | 切磋 |
| 計時競賽玩法 | 競賽對局 | 論劍 |
| 未來排名玩法 | 天梯對局 | 問鼎 |

天梯暫緩，不建立段位或排名；自由與競賽均不影響天梯，不另設「不計分」模式。競賽可供練習或正式賽事，沿用所選版本的遊戲規則。

網站涵蓋報名、隊伍確認、配對、賽程、開房、結果回收、晉級、排名及裁判操作。參賽型態稱「個人」或「團體」；個人每隊一人，團體每隊多位成員，同一賽事固定等人數並沿用座位約束。

## 設定、報名與凍結

公告固定規則版本、模組、參賽型態及各階段的賽制、交手局數／勝局門檻、時計、晉級來源／種子映射與完整排序政策。排序順序固定，不要求或提供排名同分加賽格式；算法與取值等尚未確認的內容不能作隱藏預設。初始生命依現有規則衍生，不提供自行選值。可公開報名或邀請；隊長報名、隊員確認。

F＝報名截止。名單、成員確認、必要牌組及隊長資料完成確認均在 F 起不可改；未完成必要項目的隊伍不納入賽程，並說明排除原因。隊長資料確認不同於房間報到／準備。首版沒有賽中替補；啟用個人牌組時，鎖定參賽版本整場固定，不隨帳號牌組更新。

首輪沒有既有排名／公告種子來源時，系統在 F 後對合格隊伍抽籤決定種子並自動建立賽程；抽籤結果持久保存，重試不重抽。若支援主辦指定種子，指定須在 F 前完成，不在截止後要求主辦補填或確認賽程。

T＝比賽開始時間，產品不再稱「報到期限」。報名期限與正式發布的開始時間精確到分鐘。首輪沿用建立賽事時設定的 T；後續輪次由系統自動產生開始時間，不要求主辦逐輪手動公告。T 不是最早開局限制，固定參賽者全員準備後可提前開始。首輪固定房間引用上述凍結資料；凍結、開房、玩家準備報到與真正開局是不同事實。

## 隊伍計時

每隊共用主時間，預設五分鐘；以整數分鐘設定，輸入 `0` 表示準備、行動及回合外選擇全部不限時。有限主時間耗盡後的剩餘 `0` 不等於不限時。

每階段可有不同時間設定；同階段讀秒只選 30 秒、1 分鐘或 3 分鐘，預設 30 秒，不另提供可編輯的回合外時間。交手途中不任意改時計。唯讀倒數顯示分秒，權威計時保留內部精度。

- 等待哪隊操作就扣哪隊；系統自動結算不扣。同隊多人並行等待只扣一份，不按人數倍增。
- 準備選牌也扣各隊主時間，整隊完成準備即停止。耗盡後沿目前準備視窗的實作選擇：以整隊完成該次準備為一個讀秒視窗，不因個別隊員完成重置。
- 主時間剩十秒時，先用十秒，再接完整讀秒。同行動回合連續操作不重置，剩餘讀秒不累積。
- 他隊在本隊行動回合被要求作答，先扣作答隊伍主時間，耗盡後用該次選擇的獨立讀秒。
- 當前行動隊伍的隊友作答，沿用本隊本行動回合額度，不另給或重置讀秒；不能只因玩家不同就給新額度。
- 已真正開局後斷線持續扣時，重連接續剩餘時間；普通新局重置主時間，只有淘汰和局加賽沿用時計。

回合外實例是裂地崩山：行動玩家選環境後，其他玩家依序選符合環境的手牌；原行動回合仍持續，同隊隊友也可能作答。當回合玩家抽牌後捨棄不是回合外選擇，無須作答的自動結算也不是計時選擇。

進入讀秒不判負，額度真正耗盡才判全隊負。依實際耗盡時刻判定，非輪詢或逐隊處理順序；延遲一次觀測到兩隊超時，不代表同時超時。兩隊同一時刻耗盡讀秒才是 Double Loss，僅同時進入讀秒不是。

未來天梯的超時隨機代打不在本次範圍。

## 賽制、和局與雙負

共用管理單敗、循環、雙敗、瑞士四賽制。以 Rust `tournaments` 的設計作主要參考；實際重用與能力界線見[工具選型](references/competitive-tournament-tools.md)，不依賴外部賽程生成器 API。

循環採公告的固定局數，可和局；淘汰採先取得公告勝局數，正常完成的交手須有勝負，雙負／空缺依例外處理。雙敗總決賽採重置賽：敗部冠軍首次擊敗勝部冠軍後，雙方各一敗，須再交手決勝。瑞士允許和局，不套用淘汰讀秒決勝。

### 淘汰賽和局例外

1. 遊戲正常有勝負，採正常結果，不受讀秒先後影響。
2. 遊戲和局且可區分讀秒進入先後，先進入者判負，另一隊取得該次決勝的勝局。
3. 兩隊都未進入，或同時進入無法區分先後，另開加賽，沿用時計，不補回已耗主時間；不限時則繼續不限時。再次和局重複判定，不設連續和局上限。
4. 真正同時耗盡讀秒依雙負規則，不用和局加賽取代。循環／瑞士的普通和局不追溯讀秒判負。

原始 Game Record 與 Draw 保留，另記 Competition Ruling；canonical 邊界見 [ADR0039](../adr/0039-separate-competition-rulings-from-game-conclusions.md)。

### 雙負、空缺與後續階段

雙方未按時在賽前五分鐘窗口報到，或真正同時耗盡讀秒，皆判負。兩隊退出本階段，雙敗亦不進敗部或稍後再參賽；瑞士／循環各記一負，不造勝局或和局分。缺席與計時超時保留不同原因及實際開局／時計事實。真正決賽雙負顯示「決賽雙負，冠軍空缺」，不造冠亞軍或自動並列。

循環取消退出隊伍尚未開打的後續交手，保留已完成的真實結果，不給其他隊伍虛構勝利或勝分。雙敗的退出限制與空缺處理涵蓋勝敗部、總決賽及重置賽，不能從其中任一路徑讓退出隊伍重新出賽。

既有淘汰對手位置空缺，剩餘合法隊伍輪空晉級；不遞補或復活退出隊伍，不造交手勝局／對局紀錄。兩個位置皆空則繼續傳播空缺，不指定勝者；空位不是隊伍，空缺對空缺不另記雙負。

2026-10-10 名次空缺政策已確認：保留真實賽果已確定的名次，沒有合格人選的位置空缺，不遞補、不壓縮後續名次，也不強求一定頒出三個名次。名次空缺是已確定的無人取得，不是尚待賽果或主辦判斷的未決名次；所有必要賽程及案件收尾後，賽事仍可正常結束。

雙敗敗部決賽若 B、C 雙負，兩隊退出，剩餘勝部冠軍 A 沿既定空位／輪空規則成為冠軍，亞、季軍空缺。總決賽或必要重置賽雙負時，冠、亞軍空缺，之前正常決出的第三名保留；不把第三名升成冠軍或亞軍。較早輪次的空位仍按原路徑傳播，只由後續合法賽果決定其餘名次。

已公告、尚未開始的後續階段，在前階段完賽且資格確定後：

- 至少兩隊：按實際合格隊伍進行，保留原資格與種子來源。
- 一隊：直接成為該階段勝者，不建立假比賽。
- 零隊：記錄「無合格參賽者，階段取消」及取消原因，不設勝者，並納入整場完成處置。

未決賽果或裁判案件不能當作零隊；已公告但未建立的階段不可默默略過。若資格來源指向已明確空缺的名次，該位置沒有合格隊伍，不以其他名次遞補；其餘資格確定後按實際合格隊數走上述至少兩隊／一隊／零隊處置。

### 晉級與前三名的排序判定

獎牌一律只決出整場前三名。2026-10-10 排序訪談已確認：先比自身交手積分（較高優先），同分時固定依 **勝分（較多優先）→ 負分（較少優先）** 比較，前項相同才比較下一項。所有比較項仍相同時由主辦限定判斷。血量、主時間及讀秒耗時不再用於排序，避免玩家故意超時影響排名統計；「只看勝負分」是刪除原血量／耗時比較，不移除自身積分的第一順位。

循環交手勝 3 分、和 1 分、負 0 分，空輪 0 分。瑞士預設勝／和／負／輪空為 3／1／0／3，主辦可在賽前自訂四項非負整數並公告；實際累計須完全依公告設定，包括非零敗場積分。瑞士階段同時逐項公告引擎所需的和局折算、對手勝率上下限、輪空取值與同分鍵，所有配對與階段名次都使用該階段公告值，不能在截止後補入或暗中套用預設。整場獎牌名次仍依本節排序政策判定。輪空所得積分不是實際勝場；合法缺席結果仍記自身交手戰績，雙負各記一敗、依敗場計分且退出本階段，不造勝場或和局分。

勝分取自本階段實際交手過的所有不同對手的最終交手勝場總和，負分則取同一對手集合的最終交手敗場總和。每個不同對手只計一次，不論自己對該對手勝、和或負；對手戰績包含其與自己那次交手，不跨階段累計，也不以單局勝敗代替交手勝敗。兩項不是自身賽事積分或自身勝敗場，不合併相減為單一淨分。

未真正開打的缺席配對不納入對手集合，但合法缺席結果仍是該隊的交手戰績。和局不增加勝敗場、雙負各記一敗；輪空與取消不造勝敗場。取消血量與耗時比較後，不再需要排名局樣本、加賽分母、平均精度或有效終止樣本政策；不限時、沒有有效局與超時局的平均值問題也不再構成排序需求。

所有比較項均相同時，主辦在網站決定該群組的順序與晉級資格，必填理由並公開留痕，只能處理全項相同的群組；若主辦自己在該群組，交由無利益衝突的指定裁判決定。不自動用種子、抽籤或並列解決，也不自動建立排名同分加賽或要求公告其格式。判斷前，受影響的晉級資格／名次仍未決，不得自動開始相依階段或宣布整場完成。這是 14 範圍內的限定人工例外，不代表一般裁判、更正功能全部提前實作或可任意改判、重開賽程。

瑞士階段進行中只顯示各隊目前已完成交手的自身勝場，不顯示暫時名次或對手勝分／負分；輪空積分不是實際勝場，合法缺席結果依已確認的交手戰績處理。這是進度顯示，不是正式晉級／前三名判定，也不自行改變配對依據。後輪按該階段公告的交手積分優先安排同積分合法配對，只有無法完成同積分合法配對時才跨組；存在完整同積分且不重賽的方案時，不得任意跨組。滿足此優先序的候選方案仍有多個時，系統使用固定保存的抽籤種子決定配對順序，重試不重抽、不要求主辦逐輪介入。此抽籤只決定配對，不能取代階段末正式名次或全項相同時的主辦判斷。

本政策取代原先同分隊伍間交手積分、淨勝局數及排名同分加賽的排序要求，不在新比較項之間插入其他比較鍵。

此變更不改動淘汰交手依真實結果推進的規則、季軍賽、雙敗總決賽重置賽，或上方「淘汰賽和局例外」的遊戲和局判定與時計沿用加賽；排名同分不是遊戲和局，兩種處置分開。

本輪排序政策已完成確認，[14：晉級與前三名的排序判定](tickets/14-qualification-and-podium-ranking.md) 已依核准範圍發布為 ready-for-agent；實作及指定驗證仍未完成，不因政策確認或發布票據自動放行。

完整定義須進入同一賽前公告版本，權威排名、資格解析與網站顯示使用同一政策；未定義或未取得必要事實時不能猜出唯一晉級者，也不能把它當成零隊／一隊。奇數隊的循環空輪不算勝負，只記輪空；每隊仍須與其他合法隊伍交手，雙負退出的後續取消依上方規則處理。

### 季軍賽與先後手

單敗自動安排兩支合格半決賽敗隊的季軍賽，決出唯一第三名；沿用該淘汰階段的勝局門檻與時計，與冠軍賽同輪進行，兩場皆收尾後才算該階段完成。季軍賽不復活已依雙負退出的隊伍；對手位置空缺仍依既有空缺規則處理，不造參賽者或賽果。

第一局先後手隨機；後續普通局由上一局競賽敗方隊長選擇，沒有競賽勝負的和局則交換。原始 Draw 已被競賽判負時仍由該敗方選，不自動交換；普通局時間重置與和局加賽時計沿用分開。

## 輪次開賽與裁判

前輪全部完成、配對確定後，系統自動物化下一輪及固定參賽成員；不得猜勝者或以預計結束時間替代終局。每輪全部固定房間須在該輪 T 前至少五分鐘實際就緒，供玩家進房準備報到；房間可進入後自動通知其固定成員，正常流程不需要主辦逐輪點選公告。通知是進房提醒，不是玩家已報到或房間已就緒的證據；賽事頁仍提供該輪時間及玩家的進房入口。

玩家在固定房間按準備即完成該玩家的房間報到，不另設報到操作。房間及賽程開賽授權成立後，該交手全員連線且準備便自動真正開局，不等待 T，也不等待同輪其他交手的玩家準備；前輪結果完整、固定成員及房間身分等前置仍須成立。五分鐘窗口保障尚未準備者的報到機會，不強迫已全員準備的交手等滿；物化房間不等於真正開局，房間準備亦不同於開局後依遊戲規則選牌的 Game Preparation。

尚未真正開局時，取消準備或斷線都取消該玩家的準備與房間報到；重連不自動恢復準備，須重新按準備。T 仍是未開局交手完成報到的截止：到 T 隊伍仍未全員連線且準備，該隊判負；兩隊皆未完成則皆負。已真正開局後不退回等待房或取消已成立的開局，斷線沿用隊伍計時規則。

淘汰每輪不設預期結束期限。後續輪次與新階段依兩段五分鐘窗口自動推進。E 是前輪全部交手結果與晉級配對均由賽事權威確認的時間；系統隨即固定完整下一輪配對並開始建房。A 為向下取整到分鐘的 `E + 五分鐘`，系統只在整批固定房間都已可進入時公告及開放，且不得晚於 A；T 為 `A + 五分鐘`。因此從 E 到下一輪 T 不超過十分鐘，玩家從公告到 T 有完整五分鐘。房間連結與通知不得提早暴露，通知送達時間不決定 A 或 T。

建房或放行未能在 A 前完成時，不發布部分輪次、不略過報到窗口，也不暗中延後 T；保留失敗狀態，等主辦處理。已正式發布的 T 不暗中順延。首輪開房延誤或已發布輪次的更正仍須由主辦處理，並重新滿足五分鐘；這類異常處置不成為正常逐輪進行的必要操作。

指定裁判可暫停／恢復、判棄權、安排重賽及改判，操作記原因，不能裁決自身交手。前輪改判影響已開房但尚未開打的配對，允許持久撤銷並重建，主辦重新公告 T。若與真正 GameStarted 競態，或已開打的後續交手受影響，先暫停受影響賽程，由裁判處置，保留原紀錄，不能假裝撤銷或回滾成功。

### 競賽重賽

2026-10-10 已確認：重賽直接開新局，取代原交手中的同一局位置，不另增加一個後續局號。例如第 2 局被判重賽，新局仍占第 2 局位置；原局不再計入有效局數、勝局或交手比分，只有有效替代局的結果用於後續賽程。重賽沿用固定參賽資料，不誤當淘汰 Draw 的時計接續加賽。

舊房是否繼續留存由實作依簡單程度決定，不要求保留可操作房間；原始 Game Record、遊戲結論、重賽理由與取代關係仍須可查核，不覆寫原始 canonical 歷史。舊局及舊房的遲來操作／結果不能再更新有效比分，一般重試也不能建立兩個有效替代局。此處沒有授權刪除原始查核紀錄。

同位置的新局身分與舊局歷史分開。2026-10-10 已確認：重賽沿用被取代局的先後手，不重抽、不交由原局敗方重新選擇；時計如普通新局，重置該階段完整主時間與讀秒額度，不沿用舊局消耗或讀秒進入事實，主時間設定為 0 的階段仍不限時。此功能仍屬首場正常完賽後的人工處置，不重開已結束賽程。

## 整場結束、公開與賽後更正

全部已公告階段完賽或依規則明確取消、賽果收齊且無未決裁判案件，由系統自動結束整場，不需主辦再確認。單局或單階段結束不等於整場結束。

整場進行中不觀戰，已結束局亦不提前公開重播；裁判仍可查核完整紀錄。整場結束後公開資訊重播與完整鎖定參賽牌組清單，報名的賽務資訊無需永久保密。牌組是截止時鎖定的組成，不是後改帳號牌組、洗牌順序或完整隱藏對局狀態；公開重播不自動公開隱藏資訊。自由對局觀察者政策不變。

賽後可有原因地更正賽果／名次，保留原始及更正紀錄；首版拒絕必須新增比賽或重賽才能成立的更正，不重開已結束賽程。此限制不取消賽中的改判／Waiting 房撤銷重建。
