Quick reference

一個環境，只選一個部署負責者

Cloudflare Git integration

Dashboard 連接 repository 一次，之後由 Cloudflare 監聽 push，自動 build/deploy。

不需要：.github/workflows/*.yml

仍需要：Dashboard 的 branch、root directory、build/deploy commands、secrets。

GitHub Actions

GitHub 依 workflow 執行測試、核准、migration，再以 Wrangler Action deploy。

需要：.github/workflows/*.yml

不需要：啟用 Cloudflare repository 自動部署。

fewfc 建議保留 GitHub Actions：它已有 Rust、Web、E2E gates、D1 migration、staging 自動部署與 production 手動部署。

最常見的錯誤

同時啟用 Cloudflare Git integration 的 production deploy 與 GitHub Actions deploy。同一次 push 會啟動兩條互不等待的流程，可能重複或競速部署。

判斷口訣

只要 push 後簡單 build/deploy → Cloudflare Git integration 需要跨語言測試、migration、環境核准 → GitHub Actions
